# TruyenAudio Android Native Project
- Kotlin 2.1 + Jetpack Compose
- OkHttp 4.12 + Retrofit 2.11 + SecureCookieJar (EncryptedSharedPreferences / Android Keystore)
- Foreground Service (mediaPlayback) + MediaSessionCompat + TextToSpeech
- Build: ./gradlew assembleDebug
- Output: app/build/outputs/apk/debug/app-debug.apk
